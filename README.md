# My Digital Wardrobe

A digital wardrobe and personal outfit generator built using Python and Streamlit as part of my TKS Build project.

## About the Project

I created this application to explore how technology can make fashion more interactive, organized, and personalized. Users can upload photos of clothing they own, categorize their items, and generate outfit combinations for different occasions.

## Features

- Upload clothing photos and name each item
- Organize clothes into categories such as tops, bottoms, shoes, outerwear, and accessories
- Assign clothing styles to individual items
- View and delete saved clothing items
- Generate outfits using items from the wardrobe
- Choose an occasion, such as casual, school, going out, or dressy
- Prioritize clothing that matches the selected occasion

## Technologies Used

- Python — application logic
- Streamlit — interactive web interface
- JSON — saving wardrobe information
- GitHub Codespaces — development environment

## How It Works

Users add clothing items with a name, category, style, and photo. The app stores this information and displays their wardrobe. When an occasion is selected, the outfit generator chooses a top, bottom, and pair of shoes, prioritizing items tagged with a matching style or Versatile.

This project helped me practice building a Python web application, organizing data, creating interactive features, debugging errors, and using GitHub to save and manage code.
